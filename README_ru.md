**Лучший [плагин DeepSeek Harness](https://www.deepseek.com/harness/) для анализа и управления контекстом агента.**

> Рекомендован и отмечен звёздочкой сотрудниками DeepSeek Harness [@tianyicui](https://github.com/tianyicui) и [@turtle1999](https://github.com/turtle1999) — см. [этот пост в X](https://x.com/tianyi/status/2105256532657267119).

[`dsh-context`](https://www.npmjs.com/package/dsh-context) предоставляет полный набор функций управления жизненным циклом контекста.
- **Страница «Обзор контекста»** — межсеансовый обзор как отдельная панель боковой панели (рядом с «Плагинами» и «Задачами автоматизации»): полоса KPI с 7-дневным графиком токенов/стоимости, тепловая карта активности, агрегированное кольцо состава и фильтруемые карточки сеансов с переходом в любой сеанс.
- **Вкладка «Контекст»** — панель контекста в UI для статистики контекста, состава, тренда, событий, сообщений и команд DeepSeek Harness.
- **Вкладка «Флот»** — отдельная страница семьи агентов: текущий агент, его родители и каждый субагент в виде живой карточки.
- **Панель контекста** — та же панель как вкладка правой боковой панели: выберите **Контекст** на странице-подсказке боковой панели, и панель откроется рядом с чатом, включая сеть агентов.
- **Команда `/context`** — слэш-команда показывает модель контекста для текущего состава контекста и недавнего развития контекста.

## Установка / обновление

### Установка в DeepSeek Harness web или desktop

Введите `dsh-context` в поле поиска мастера **Добавить плагин** и нажмите **Установить**:

![Мастер добавления плагина](https://raw.githubusercontent.com/bowenliang123/dsh-context/main/docs/add-plugin-wizard.png)

### Установка через CLI `dsh`

Установите плагин [`dsh-context`](https://www.npmjs.com/package/dsh-context) из [DeepSeek Harness](https://www.npmjs.com/package/@deepseek-ai/dsh):

```sh
dsh plugin --profile web add dsh-context
```

Или обновите плагин `dsh-context`:

```sh
dsh plugin --profile web update dsh-context@latest
```

Затем запустите веб-интерфейс командой `dsh web`. Без шага сборки и перезапуска.

## Использование

Пять поверхностей, одна история — что несёт ваш агент, как это появилось и что он с этим сделал:

| Где | Что вы получите |
| --- | --- |
| **Страница «Обзор контекста»** | Каждый сеанс с первого взгляда: использование, стоимость, попадания в кэш, ежедневная активность и профили контекста по сеансам — фильтры по диапазону, дню, группе или поиску, один клик для перехода. |
| **Вкладка «Контекст»** | Полная панель: статистика, состав, тренд по запросам, события, активность файлов и выполнения команд — в каждом сеансе. |
| **Вкладка «Флот»** | Сеть агентов: текущий агент, его родители и каждый субагент в реальном времени. |
| **Команда `/context`** | Центрированное модальное окно с тем же составом и обозревателем контекста, не покидая чат. |
| **Карточка настроек** | Пользовательские значения по умолчанию: точка входа панели, диапазон обзора, тренд и сортировка, а также префикс/суффикс системного промпта вокруг каждого сеанса. |

| Раздел | На какой вопрос отвечает |
| --- | --- |
| **Полоса KPI** | Сколько я использую — сеансы, активные в выбранном диапазоне (7д / 30д / все), с оплаченными токенами, оценочной стоимостью, долей попаданий в кэш и ходами, сгруппированными по дню начала каждого шага; запуски инструментов и активное время охватывают эти сеансы и всё время жизни их субагентов, как в карточке статистики времени. |
| **График использования за 7 дней** | Когда я сколько потратил — оплаченные токены и оценочная стоимость каждого из последних 7 дней в виде пары столбцов, агрегированные по дню начала каждого запроса в его сеансе (не по дню последней активности сеанса). |
| **Тепловая карта активности** | Когда я действительно работаю — последние 8 недель ежедневных оплаченных токенов; щёлкните день, чтобы отфильтровать сеансы и ограничить три счётные карточки этим днём. |
| **Загрузки навыков** | Какие навыки я загружал, как часто и как недавно — загрузки по навыкам за диапазон; щёлкните навык, чтобы отфильтровать сеансы, которые его загружали. |
| **Вызовы инструментов** | Какие инструменты запускались, как часто и как недавно — запуски по инструментам из ежедневного журнала; щёлкните инструмент, чтобы отфильтровать сеансы, которые его запускали. |
| **Выполнения команд** | Какие программы запускались, как часто и как недавно — запуски команд по программам за диапазон, учитываемые при отправке; щёлкните программу, чтобы отфильтровать сеансы, которые её запускали. |
| **Точка входа настроек** | Чип в шапке страницы — тот же защищённый переход к настройкам этого плагина, что и карточка «О плагине» на вкладке «Контекст». |
| **Состав контекста** | Куда ушли оплаченные токены выбранного диапазона, в разбивке по оплачиваемым категориям карточки токенов (вызовы инструментов, рассуждение, ответы, …). |
| **Карточки сеансов** | Профиль каждого сеанса под четырьмя карточками: кольцо состава, оплаченные токены, ходы, стоимость и хлебная крошка рабочей области/проекта — сортировка по недавности, токенам или размеру контекста, поиск, группировка по рабочей области. Клик по карточке открывает сеанс. |

## 📊 Вкладка «Контекст»

Откройте любой сеанс и нажмите вкладку **Контекст**:

![Обзор панели контекста](https://raw.githubusercontent.com/bowenliang123/dsh-context/main/docs/context-overview.png)

| Карточка | На какой вопрос отвечает |
| --- | --- |
| **Статистика контекста** | Ходы, шаги, человеческие вводы, текущие вызовы инструментов — плюс стоимость, оценённая по прайс-листу models.dev (наведите на `?` для тарифов за 1 млн; только DeepSeek делит пиковые/льготные тарифы: указанные тарифы — льготные, а пиковые окна оплачиваются по 2×). |
| **Статистика токенов** | Куда ушли оплаченные токены — та же сумма, что в строке статистики чата под композером, в разбивке на системный промпт, схемы инструментов, сообщения пользователя, внедрённый контекст, внедрения навыков, вызовы инструментов, рассуждение и ответы. «Вызовы инструментов» объединяет имена и аргументы вызовов (повторяемые в промпте и генерируемые в выводе) с результатами, которые вернули инструменты; «Ответы» выделяет текст ответа модели из того же содержимого ассистента и вывода; «Рассуждение» так же выделяет размышления; доля попаданий в кэш сеанса показана в углу. |
| **Статистика времени** | Как активное время распределилось между вызовами модели, запусками инструментов и накладными расходами. |
| **Текущий контекст** | Что находится в окне *прямо сейчас*. |
| **Тренд контекста** | Размер каждого запроса — и его история. |
| **Обозреватель контекста** | Из чего *на самом деле* собран любой запрос. |
| **События контекста** | Когда и почему окно изменилось. |
| **Активность файлов** | Что агент *сделал* с вашими файлами. |
| **Выполнения команд** | Что агент запускал, как завершался каждый запуск и на какие программы он опирался. |

Оценка стоимости следует одному документированному набору правил: [Как сопоставляются цены моделей](docs/model-pricing-mapping.md).

Заголовочные показатели занятости и состава читают **те же официальные проекции token-meter, что и кольцо контекста композера чата** (`contextPressure` / `contextBreakdown`), поэтому цифры всегда совпадают с тем, что показывает кольцо — процент карточки — это та же занятость с одним десятичным знаком.

Ячейка «Сеть агентов» карточки **Статистика контекста** (оплаченные токены и оценочная стоимость всей семьи) ведёт на вкладку **Флот**. Её пилюли «Ввод / вывод» тоже являются ссылками: **Человеческие вводы** открывает **Обозреватель контекста** на ваших сообщениях, а **Чтение / Запись / Поиск / Изображения** открывают карточку **Активность файлов** с выбранным типом.

### 🧱 Текущий контекст — что сейчас в окне контекста

![Карточка «Текущий контекст»](https://raw.githubusercontent.com/bowenliang123/dsh-context/main/docs/current-context.png)

Шестицветная составная полоса на фоне полного окна модели (две штрихованные маски в конце = резерв автосжатия: его буфер, затем зарезервированное окно вывода запроса): системный промпт, схемы инструментов, сообщения пользователя, внедрённый контекст, ответы ассистента, результаты инструментов — каждый с ≈числом токенов и долей. Когда разговор начинает деградировать, именно здесь видно, *какая часть* за это отвечает.

### 📈 Тренд контекста — как контекст рос и менялся по ходам или шагам

![Тренд контекста с краткой сводкой шага](https://raw.githubusercontent.com/bowenliang123/dsh-context/main/docs/context-trend.png)

Один составной столбец на запрос к модели — детальнее, чем по сообщениям, — так вы видите, как окно растёт ход за ходом:

- **✨ Краткая сводка шага** — три строки простым языком под графиком: **Пользователь** напоминает сообщение, открывшее ход, **Вход** перечисляет, что нового вошло (обычно результаты предыдущих инструментов), **Ответ** показывает ответ и/или вызванные инструменты. Щёлкните строку, чтобы открыть это сообщение в обозревателе контекста.
- **✂ отмечает события** — сжатия и очистки закреплены на столбце, где произошли, поэтому провалы объясняют себя сами.
- **Читайте как удобно** — гранулярность **Шаг / Ход**, **Всего** (накопительный состав) или **Дельта** (знаковое изменение каждого запроса) и горизонтальная прокрутка по всему сеансу. В режиме «Дельта» рост накапливается выше базовой линии, а сжатие уходит ниже неё:

![Тренд контекста в режиме «Дельта»](https://raw.githubusercontent.com/bowenliang123/dsh-context/main/docs/history-delta.png)

- **Обзор** — один переключатель сжимает весь сеанс (шаги или ходы) в ширину панели как непрерывную составную ленту: каждый провал сжатия и сдвиг состава виден сразу, без горизонтальной прокрутки и без догрузки. Метки показывают квартили и полный диапазон; наведите для чтения, наведите на полосу, чтобы подсветить категорию по всей ленте; щелчок закрепляет шаг и открывает категорию полосы в обозревателе (несовместимо с режимом ДНК и «Адаптивно»).
- **Наведение и закрепление** — прокрутите для мгновенной подсказки; щёлкните, чтобы закрепить полную разбивку с **фактическими промптом / выводом / кэшем** от провайдера рядом с оценками.
- **Живая связь** — при наведении на столбец предпросмотр собранного контекста шага показывается в обозревателе контекста рядом с графиком; покинув график, вы вернётесь к своему выбору.

### 🧭 Обозреватель контекста — откройте коробку любого запроса

Выберите **Живой (следующий запрос)** или любой сохранённый шаг и просмотрите, из чего был собран этот запрос: семь сворачиваемых категорий раскрываются в строку на элемент с ценой в токенах, и каждый элемент раскрывается в своё **фактическое содержимое** — системный промпт, JSON-схему каждого инструмента, текст сообщений, рассуждения, аргументы инструментов и вывод инструментов. Содержимое навыков (каталог доступных навыков, вызовы `/skill` и загрузки инструментом `skill`) имеет собственную категорию **Внедрения навыков**, поэтому контекстный след скрытного навыка не может спрятаться в корзинах внедрённого контекста и результатов инструментов.

- **Кто предоставляет каждый инструмент** — каждая строка схемы инструмента несёт по возможности чип источника: пакеты `tool-*` первой стороны, пакеты возможностей `dsh-*`, прокси `mcp:<server>` или точный плагин, наблюдаемый вживую из `tools.register()`. Сортируйте по **размеру / имени** и фильтруйте каждую категорию по её собственным искомым полям:

![Схемы инструментов с чипами источников, фильтром и сортировкой](https://raw.githubusercontent.com/bowenliang123/dsh-context/main/docs/context-browser-tools.png)

- **Фильтр ответов ассистента по типу** — поле поиска категории ассистента несёт чипы **Рассуждение / Инструменты / Ответ**, каждый считает ответы этого типа в текущих результатах поиска (один ответ может нести несколько); щёлкните, чтобы оставить только подходящие ответы, ещё раз — чтобы снять:

![Ответы ассистента с чипами фильтра по типу](https://raw.githubusercontent.com/bowenliang123/dsh-context/main/docs/context-browser-assistant-kinds.png)

- **Результаты инструментов раскрываются в полный вызов** — имя инструмента и аргументы со статусом **OK/ошибка**, тело результата с числом строк и переключателем **Необработанный / Markdown**:

![Результат инструмента, раскрытый с переключателем «Необработанный / Markdown»](https://raw.githubusercontent.com/bowenliang123/dsh-context/main/docs/context-browser-tool-result.png)

- **Вложения отображаются упорядоченными карточками** — блоки `image` и `file` сообщения стоят вместе в порядке, в котором сообщение их несёт, по одной карточке: изображения с миниатюрой, размерами, сохранённым размером и официальной оценкой токенов изображения DeepSeek; другие файлы с глифом типа, расширением и сохранённым размером. Один щелчок открывает вложение в собственной колонке предпросмотра dsh (просмотрщики Markdown, кода, PDF, офисных документов и изображений) под настоящим именем файла:

![Карточки изображений-вложений с размерами, сохранённым размером и оценкой токенов](https://raw.githubusercontent.com/bowenliang123/dsh-context/main/docs/context-browser-images.png)

- **Сравнение с предыдущим ходом** — знаковые бейджи изменений по категориям (`+N` элементов, `±Nk` токенов) сразу показывают, что ход добавил или вернул. Шаги старше сжатия реконструируются из архива удалённых сообщений — и карточка сообщает, если состав шага лишь приблизителен.

- **Режим ДНК раскладывает весь контекст плоско** — полоса рисует по одной полосе на элемент в порядке чтения моделью, а ниже те же элементы становятся плоским списком с новейшим сообщением сверху (модель читает от старых к новым, поэтому список идёт в этом порядке снизу вверх): каждая строка несёт позицию в промпте (`#12`), категорию, вводящий шаг и цену в токенах и раскрывается в то же полное содержимое; схемы инструментов и системный промпт закрывают список двумя групповыми строками. Карточка заканчивается вровень с карточками состава и тренда рядом — полностью разложенный сеанс прокручивается внутри, а не заливает страницу.

### ⚡ События контекста — когда и почему окно изменилось

![События контекста со сжатием](https://raw.githubusercontent.com/bowenliang123/dsh-context/main/docs/context-events.png)

Каждое внедрение, сжатие, очистка, смена модели и переключение режима плана — с меткой производителя (файл инструкций, id плагина, имя навыка), чистым изменением токенов (сжатия показывают, что вернули), ходом/шагом и временем. Чипы **Внедрение / Сжатие / Очистка / Смена / Режим** фильтруют журнал по типу, каждый несёт счётчик событий всего сеанса.

### 📁 Активность файлов — что агент сделал с вашими файлами

![Активность файлов](https://raw.githubusercontent.com/bowenliang123/dsh-context/main/docs/file-activity.png)

Строка на каждый затронутый файл — чтение, запись или поиск — агрегированная до шага, выбранного на графике тренда:

- **Счётчики по назначению** с чипами заголовка, одновременно служащими фильтрами (**Прочитано / Записано / Найдено / Изображения**), и поле поиска по пути.
- **Изменения строк** — каждый `edit`/`write` вносит свой оценочный след `+добавлено / −удалено`, по файлу и суммарно.
- **Учитываются все режимы** — нативные инструменты, `str_replace_editor` из пресета Minimal и вложенные вызовы внутри программ PTC `run_code` сворачиваются в строки по инструментам.
- **Поиск попадает в реальные файлы** — найденные файлы получают собственные строки операций с числом совпадений.
- **Щёлкните строку**, чтобы развернуть полный журнал операций — каждая операция сразу ведёт к точному результату инструмента в обозревателе контекста.
- **Щёлкните имя файла**, чтобы открыть его предпросмотр в правой боковой панели, как в встроенной боковой панели файлов — тот же просмотрщик, то же поведение с вкладкой на файл. В harness без этой колонки имя, как и раньше, открывается в вашей системе.

### 🖥️ Выполнения команд — что запускал агент

![Выполнения команд](https://raw.githubusercontent.com/bowenliang123/dsh-context/main/docs/command-executions.png)

Каждый запуск shell и кода со статусом, длительностью и меткой шага, а также сводка сеанса, ярлыки внимания и рейтинг программ. Факты внимания и рейтинг остаются по всему сеансу, а поиск и чипы статуса сужают список. Каждый щелчок на рейле записывает свой ракурс в поле поиска — щелчок по программе заполняет и подсвечивает программу, повторный щелчок очищает оба — поэтому поле всегда показывает, что фильтрует список.

## 🚢 Вкладка «Флот»

Откройте любой сеанс и нажмите вкладку **Флот** (справа от **Контекст**) — семья агентов на отдельной странице: полоса сводки, карточки **Сеть агентов** и **Межагентная совместная работа**, ниже — **Задачи командной работы** и **Проверка событий**.

![Страница флота для команды из шести агентов: сводка флота, сеть агентов, межагентная совместная работа, задачи командной работы и проверка событий](https://raw.githubusercontent.com/bowenliang123/dsh-context/main/docs/fleet-overview.png)

Полоса сводки считает агентов, работающих агентов, рабочие элементы и сообщения. Выбор агента на графе или в дорожке сужает представление совместной работы до этого агента, поэтому страница отвечает за одного участника за раз.

### 🕸 Сеть агентов — семейный портрет

Текущий агент, его родители и каждый субагент — по карточке на агента: заголовок, размер живого контекста и занятость окна, полоса состава, а также сколько он работает и сколько шагов сделал. Рёбра расходятся от каждого родителя в цвете линии — наведите на карточку, чтобы подсветить всю цепочку и прочитать полную разбивку в полосе деталей; щёлкните узел, чтобы подсветить его. Работающие агенты дышат зелёным пульсом на входящем ребре и вращают собственный роллинг-спиннер harness рядом с заголовком, который после завершения работы превращается в ту же зелёную точку, что использует список субагентов в шапке; узкие панели складывают семью в аккуратные строки — никогда не горизонтальная прокрутка.

### 🛰 Межагентная совместная работа — семья на одной временной шкале

У каждого агента своя дорожка на общей временной шкале: межагентные сообщения, метки задач команды и записи делегирования, а тихие дорожки сворачиваются за переключателем. Номера задач обозначают задачу между дорожками — повторяющиеся номера означают одну и ту же задачу — а наведение связывает записи, относящиеся друг к другу. **Earliest / Latest** меняет порядок, поиск сужает дорожки, а щелчок по задаче фильтрует временную шкалу и показывает её.

### ✅ Задачи командной работы — кто что делает

Доска **Задачи командной работы** объединяет задачи команды и делегирования субагентам — группы владельцев, фильтры статуса (Все / В работе / Ожидают / Готово) и связи «заблокировано», подсвечивающие всю цепочку предварительных условий при фокусе на задаче. Каждая карточка несёт владельца, описание, области записи и итоговый ответ; щёлкните задачу, чтобы открыть полное описание на месте, в исходном или отрендеренном виде.

### 📡 Проверка событий — кто что кому сказал

Карточка **Проверка событий** автоматически читает журналы сеансов семьи — без шага сканирования. Сообщения, отчёты и записи делегирования фильтруются в один поток: выберите узел временной шкалы или запись потока, чтобы увидеть полную запись — журнал сеанса, откуда она пришла, и её последовательность, уведомление, когда завершение записала среда, а не дочерний агент, полный итоговый отчёт (со структурированным результатом или диагностикой) и карточки участников, открывающие чат этого агента в боковой панели или в полном виде. Фильтруйте по типу или тексту, а общий выбор агента сужает весь хаб.

Панель **Контекст** правой боковой панели сохраняет ту же карточку семьи встроенной, поэтому семья остаётся в одном клике, пока вы читаете чат. Не нужна вкладка? Отключите **Вкладку флота** в карточке настроек — карточка продолжит жить в этой панели, а ячейка семьи на вкладке «Контекст» откроет её там, когда доступна боковая панель.

## ⚙️ Настройки

Карточка настроек **Контекст** содержит пользовательские настройки этого плагина — **точку входа панели контекста** (вкладка **Контекст** в разговоре, панель правой боковой панели, обе или «Скрыть» для ни одной — переход из строки ответа идёт вместе с ней), собственный переключатель показа/скрытия вкладки **Флот** (точка входа панели никогда его не контролирует), диапазон по умолчанию **Обзора контекста** (Сегодня / Последние 7 дней / Последние 30 дней / Все, по умолчанию последние 30 дней; выбор пресета на странице записывает его обратно), гранулярность тренда (Шаг/Ход), режим тренда (Всего/Дельта), кривая длительности (показывается по умолчанию), порог автоматического обзора тренда, база сравнения обозревателя контекста, сортировка инструментов и активности файлов и переключатель показа/скрытия обзора контекста. Она живёт на странице **Плагины**: запись боковой панели **Плагины** → страница бандла **dsh-context** → его раздел **Конфигурация** (карточка обслуживается живой формой конфигурации записи).

Строки **Системный промпт · Префикс / Суффикс** содержат свободный текст, добавляемый в самое начало / конец системного промпта каждого сеанса для всех агентов (включая субагентов) — персона или правило поведения для развёртывания, использующее собственную сборку промпта harness. Изменения применяются со следующего хода; оставьте строку пустой, чтобы отключить её.

Кнопки пресетов «Обзор контекста» записывают выбор обратно как сохранённое значение по умолчанию; все остальные переключатели на графике и в карточках остаются для текущего просмотра и никогда не перезаписывают сохранённую настройку.

![Карточка настроек «Контекст»](https://raw.githubusercontent.com/bowenliang123/dsh-context/main/docs/settings.png)

## Полезно знать

- **След в кэше** — плагин сохраняет в кэш проекций dsh только компактную сводку по сеансу (состав, счётчики, стоимость/время, информация о модели); тяжёлые детали по событиям (текст поверхности, разбивка запросов, операции с файлами, программы команд, интервалы) сворачиваются заново из долговечного журнала, когда они нужны панели, поэтому кэш остаётся небольшим даже в длинных сеансах. Детальные представления ограничены (шаги 1500 · ходы 300 · события 400 · узлы поверхности 2000 · архив 400 · операции с файлами 400 · команды 400).
- **Оценки и фактические значения** — цифры категорий используют собственную эвристику фиксированной плотности dsh (ту же, что встроенный измеритель токенов); закреплённые детали тренда показывают рядом фактические значения провайдера, а карточка токенов сочетает ≈оценочные доли состава с точной оплаченной суммой провайдера.
- **Совместимость** — работает с `@deepseek-ai/dsh` начиная с **0.2.0-rc.2** (линии `0.2.0` и `0.2.1` проверены на их rc.2-релизах, линия `0.2.2` — на её rc.1-релизе), поколение журнала сеансов V4, из одного пути, управляемого формой. Матрица по релизам и способ проверки: [docs/compatibility.md](docs/compatibility.md).
- **I18n** — интерфейс на 简体中文, English, 日本語, Español, Français, Deutsch, Русский и Português (переключение языков требует dsh 0.2.2+; более ранние поддерживаемые линии предлагают только китайский и английский).
